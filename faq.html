FAQ

Frequently asked questions.

Answers about access, permissions, data, and what to expect from the community preview.

01What is Security Graph Explorer?+

A native Windows application that turns Microsoft Defender XDR Advanced Hunting results into navigable investigation graphs, so you can follow relationships between devices, identities, IPs, and evidence without losing the query behind the picture.

02Is this an official Microsoft product?+

No. It is an independent, personal open-source project. It is not affiliated with, endorsed by, or sponsored by Microsoft.

03What access does it need?+

Delegated Microsoft Graph access with the ThreatHunting.Read.All permission. You bring your own Microsoft Entra application; there is no client secret and no shared backend.

04Where does my data go?+

Nowhere but your own tenant. Queries run through Microsoft Graph using your delegated credentials, and results stay on your device.

05What is a .sggraph file?+

A versioned bundle that stores a graph definition: its KQL query, column mapping, and display settings, so you can save, share, and reuse investigations.

06Do I need to know KQL to use it?+

Basic familiarity helps if you want to write custom queries, but the app ships with reusable graph templates so you can start investigating without writing KQL yourself.

07When will it be available?+

Security Graph Explorer is on track to publish as a Microsoft Store app on December 1, 2026. Until then, it is in active community preview.

08Is it free?+

Yes. It is a free, open-source preview project.

09How can I give feedback or contribute?+

Reach out through the creator's LinkedIn, linked from the Meet the creator section, with ideas, issues, or graph templates you would like to share.
